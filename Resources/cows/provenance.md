# cowfile provenance

Cowsaver bundles 47 static cowfiles from [cowsay 3.8.4](https://github.com/cowsay-org/cowsay/tree/v3.8.4). The four cowfiles in that release that require executable Perl (`small`, `sus`, `three-eyes`, and `udder`) are omitted because Cowsaver renders static templates only.

Each included `.cow` file retains its original `##` header, including any artist attribution. The GPLv3 text supplied with the bundle is in `license.txt`.

Some cowfiles depict recognizable characters or marks. They are included as received from cowsay; Cowsaver claims no affiliation, endorsement, trademark, or character rights.
