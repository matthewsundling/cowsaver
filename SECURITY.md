# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x and earlier | No |

## Reporting a vulnerability

Do not report suspected security vulnerabilities in a public issue. Use GitHub's private vulnerability-reporting flow for this repository. If that route is unavailable, email [security@matthewsundling.com](mailto:security@matthewsundling.com). Include the affected version, a clear description, and steps to reproduce when possible.

Cowsaver does not use a network service or process untrusted code. Reports involving bundled or imported content, configuration files, installation, or macOS screensaver behavior are still welcome.
